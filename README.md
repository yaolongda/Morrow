> 朝朝暮暮，皆有安排。

**朝暮（Morrow）** 是一款参考 macOS 日历设计的 Windows 桌面日历：四种视图、灵活可调的重复日程、可自定义的工作休息节奏与上下班时间、跨周 / 跨月 / 跨年的长期计划、法定节假日与调休、四种桌面小组件，以及一套完整的设置中心。所有数据只保存在本机。

[English](README.en.md) · [离线 HTML 说明](README.html) · [GitHub](https://github.com/yaolongda/Morrow)

## 下载

前往 **[Releases](../../releases/latest)** 下载最新 Windows 安装包：

```text
朝暮-Morrow-Setup-1.2.1.exe
```

- Windows 10 / 11（x64）
- 按当前用户安装，无需管理员权限；自动创建桌面与开始菜单快捷方式
- 可在「设置 → 应用」中卸载，卸载不会删除日程数据
- 安装包未签名；若出现 SmartScreen，请选择「更多信息 → 仍要运行」
- 便携版：解压 `朝暮-Morrow-v1.2.1-Portable.zip`，运行 `朝暮-win32-x64\朝暮.exe`，无需安装

> 安装包约 107 MB，超过 GitHub 普通仓库的单文件限制，因此作为 Release 附件发布。

## 核心功能

### 日历

- 月 / 周 / 日 / 年四种视图，今天高亮，支持全天、多日与跨月日程。
- 周 / 日视图拖出时间段即可新建日程；月视图双击日期快速创建。
- 多日历配色、显隐、右键重命名或删除；标题 / 地点 / 备注即时搜索。
- 本地 JSON 原子持久化，不联网、不上传。

### 重复日程

- 支持 **每天、每个工作日、每周（任选星期几）、每两周、每月、每季度、每年** 七种重复方式。
- 可设置重复结束日期；留空表示一直重复。
- 编辑重复日程时，可选择 **仅此日程 / 此后全部 / 所有日程**：只改当次、从这一次开始改到未来、或更新整个系列；移动日期时整个系列会一起平移。
- 删除同样区分 **仅本次 / 此后全部 / 全部系列**；「此后全部」会保留过去的历史记录。
- 重复实例在月、周、日、年视图与四种桌面小组件中自动展开，并以 ↻ 标记提示。
- 搜索结果会定位到最近一次重复实例，而不是系列第一次出现的日期。

### 日程提醒

- 每个日程都可以设置提醒：提前 **5 / 15 / 30 分钟、1 小时、1 天**，或自定义分钟数。
- 到点后在主窗口弹出温和的提醒卡，可以选择「5 分钟后提醒」或直接打开日程。
- 可以额外勾选 **Windows 系统通知**；程序最小化到托盘时，提醒仍由主进程定时器触发。
- 提醒计算全部在本地完成，不上传任何数据。

### 日程与计划的日常操作

- 周 / 日视图里全天日程太多时，会自动折叠并显示「还有 N 个全天日程」，点一下展开。
- 日程和计划的增删改都支持 **Ctrl+Z 撤销 / Ctrl+Shift+Z 重做**。
- 删除的日程和计划会进入 **回收站**，保留 30 天，可在「设置 → 回收站」恢复或彻底清理。

### 上下班与下班庆祝

- 在「设置 → 工作时间」里设置班次：**上午 + 下午**、**全天** 或 **夜班**，并分别填写上下班时间。
- 「今天」小组件会显示实时状态：距上班、距午休、距下班还有多久；休息日则安静地写一句「好好生活」。
- 午休时有一场轻量的庆祝；真正下班时，会有更完整的粒子动画和一句下班诗。
- 如果第二天是周末或法定节假日，最后一天下班的庆祝会自动升级，诗也会换成「假期前夜」的那一首。
- 夜班按跨午夜处理，早上结束同样会庆祝。
- 所有庆祝只发生在「今天」小组件里，不弹系统通知，不打断你正在做的事。

![上下班时间](docs/settings-work-hours.png)

### 法定节假日

- 内置 **2024–2026** 年中国法定节假日与调休补班安排：放假自动标为休息，调休日自动标为上班。
- 月视图会显示节日名称，设置中心的特殊日期会标出节日圆点。
- 特殊日期优先级最高：把某一天点成「补班」，就是「今天加班，不放假」。
- 支持导入社区维护的节假日 JSON，扩展 2027 及之后的年份；内置数据不会被覆盖，可随时恢复。
- 可以在「设置 → 工作时间」关闭节假日同步，完全按自己的休息规则走。

### 工作节奏

- 自定义每周起始日：**周一 / 周日 / 周六**。
- 休息规则预设：
  - 双休、单休
  - 大小周（大周双休、小周单休）
  - 上三休一
  - 周六上半天
  - 周六半天大小周
  - 月休五天（自设）
  - 完全自定义：逐天设置工作 / 半天 / 休息
- **特殊日期**：任选日期切换为休息、半天或补班，支持调休与临时安排；也可以按日期段批量设置。
- **班次模板**：把当前班次和时间保存成模板，A 班 / B 班 / 夜班一键切换。
- 休息日会在月 / 周 / 日 / 年视图、迷你日历与桌面小组件中柔和高亮，并随时同步。

![工作时间设置](docs/settings-work.png)

### 长期计划

- 给计划设置开始与结束日期，支持从几号持续到几号。
- 自动识别并视觉区分：
  - **短期 · 跨周**：3 周以内
  - **中期 · 跨月**：3 周至约 4 个月
  - **长期 · 跨年**：超过 4 个月或跨年
- 在月视图中以浅色进度条横跨日期，在周 / 日视图中显示计划带，不喧宾夺主。
- **按时间自动推进**：新建计划默认按日期自动计算进度，也可以关掉开关手动拖动。
- **自定义提醒节点**：在计划里添加「第一阶段验收」「中期复盘」这样的日期；到节点当天，会弹出一张温和的提醒卡，配一句诗，不会用系统通知打断你。
- 经过 **20 / 50 / 75 / 80 / 90 / 100%** 里程碑时，会随机送上一句励志古诗；每个里程碑也可以自定义文案。
- 计划支持归档，并按「进行中 / 已完成 / 已归档」筛选，不再需要删除已经结束的计划。
- 临近截止时，用一句诗温和提醒；侧边栏展示进行中的计划、进度与今日节点。

![计划编辑器](docs/plan-editor.png)

### 桌面小组件

四种小组件：月历、今天、即将到来、月历与议程。

- 拖动卡片自由移动；**不再限制大 / 中 / 小预设尺寸**，拖动右下角手柄或窗口边缘即可像主窗口一样自由缩放。
- 布局会随尺寸自动变化：宽屏时月历与议程并排，窄屏时自动堆叠；字号和可见日程数量也会跟着调整。
- 小组件跟随全局主题、强调色、字体、面板透明度、毛玻璃与背景图片，并带有轻微的入场动画。
- 同一种小组件可以添加多个；每个小组件可以单独覆盖主题、不透明度与毛玻璃，并记住所在显示器。
- **锁定位置与尺寸**后固定不动；置顶、关闭；位置、尺寸与锁定状态会在重启后恢复。
- 今日小组件显示农历、节气与上下班倒计时，并在下班时播放庆祝动画。
- 点击小组件中的日期或日程，会打开主日历并定位。

### 小组件怎么回答问题

四个小组件不再各自解释数据，而是共用同一套「结论引擎」：

- **今天**：回答「还要熬多久、现在干嘛」。显示当前时段的重点、下一件事、今天还剩多少可自由支配的时间，以及一句可关闭的节奏建议。
- **即将到来**：回答「接下来要面对什么、计划走到哪」。按冲突风险、是否需要准备、计划节点与临近程度排序，悬停可看排序原因；底部显示计划的完成进度与时间进度、下一个里程碑。
- **月历**：回答「这个月节奏如何、哪里忙哪里空」。给出一句本月节奏结论，并用日期密度和「最忙的一天」标出忙闲。
- **月历与议程**：回答「今天 / 本周具体安排是什么」。显示选中日期的完整时间线、任务数与空状态。

同一时间差、进度、冲突与任务的文案格式在四个组件中完全一致。临近下班 1 小时内，今天组件会极轻微地呼吸一下；默认态其他时候没有持续动效。智能排序、呼吸动画和节奏建议都可以在「设置 → 显示 → 小组件」里单独关闭。

### 更多能力

- **小组件多开与独立外观**：同一种小组件可以开多个（最多 10 个），每个都可以单独设置主题、不透明度和毛玻璃，并记住所在显示器。
- **iCalendar**：导入 / 导出 `.ics`，可按日历与日期范围导出；导入时按 UID 去重，全程本地解析。
- **任务清单**：侧边栏「今日任务」快速添加、勾选；「全部任务」面板支持截止日期与删除，月视图显示当天任务数。
- **日程模板**：把常用日程存成模板，新建时一键套用标题、时长、地点、提醒与颜色。
- **标签颜色与备注图片**：单个日程可用自己的标签色；备注框可直接粘贴图片（最多 3 张，自动压缩后本地保存）。
- **ISO 周数与历史导航**：月视图左侧、周视图标题显示周数；标题栏返回 / 前进，或 `Alt+←` / `Alt+→`。
- **托盘迷你日历**：单击托盘图标弹出迷你月历，可直接新建日程或打开某一天。
- **打印与图片**：打印当前视图（可另存 PDF），或把当前视图导出为 PNG。
- **自定义快捷键**：今天、日周月年、新建计划、前后范围都可以改键。
- **农历增强**：黄历新增冲煞；日程支持「每年（农历生日）」重复。
- **数据分片**：日程超过 2000 条时按年份写入 `events/YYYY.json`，避免单个 JSON 越来越大；数据减少后自动合并清理。

### 设置中心

点击工具栏齿轮，或按 `Ctrl + ,`：

- **通用**：周起始日、侧边栏、配置导入导出、数据文件夹。
- **工作时间**：休息规则预设、自定义工作日、上下班班次与时间、法定节假日同步、特殊日期调休 / 加班。
- **外观**：
  - 经典白 / 暖纸 / 晨雾三套主题
  - 强调色（7 种预设 + 自选颜色）
  - 字体（系统、微软雅黑、等线、宋体、楷体、霞鹜文楷）
  - Windows 11 **Mica / 亚克力**窗口材质
  - 面板不透明度、毛玻璃模糊
  - 导入自己的背景图片，可调节透明度、模糊与暗化
- **显示**：农历、二十四节气、黄历宜忌、星座运势，以及计划显示开关。
- **计划**：计划类型说明、进行中的计划、新建计划。- **关于**：版本、简介、Slogan、项目主页与检查更新。

## 快捷键

| 快捷键 | 功能 |

## 数据与隐私

```text
%APPDATA%\朝暮\
├─ calendar-data.json    # 日历、计划、设置、任务等
├─ events\YYYY.json      # 日程超过 2000 条时按年份分片
├─ widgets.json          # 小组件位置、尺寸、主题、显示器与锁定
└─ window-state.json     # 主窗口大小与位置
```

- 不访问网络、不上传任何数据。
- 配置导出包含全部日历、日程、计划、设置与小组件布局。
- 删除 `calendar-data.json` 可恢复示例数据；卸载不会自动删除数据。
- 从旧版「日历」升级时，会自动迁移原有日程与小组件数据。

## 技术栈

- Electron 45
- 原生 HTML / CSS / JavaScript，无前端框架、无运行时 NPM 依赖

- 法定节假日与调休数据本地内置（chinese-days，MIT）
- Chromium DevTools Protocol 端到端测试
- electron-builder + NSIS

## 已知边界

- 农历与节气为本地计算；黄历宜忌为传统建除十二神的简化呈现，星座运势为本地生成的娱乐内容。
- 法定节假日数据内置 2024–2026 年安排（来源 chinese-days，MIT）；更晚年份可导入节假日 JSON 扩展，也可通过特殊日期手动补充。
- Mica / 亚克力需要 Windows 11；旧系统会回退到普通窗口。
- 团队协作与账户同步尚未实现；系统通知为可选功能，需要 Windows 支持。
- 界面目前只提供简体中文；繁体中文界面尚未加入。
- 回收站保留 30 天，到期后自动清理。
- 安装包与便携版未签名，SmartScreen 可能提示。
- 小组件是独立窗口，置顶时会浮于其它应用之上。
