> 朝朝暮暮，皆有安排。

**朝暮（Morrow）** 是一款参考 macOS 日历设计的 Windows 桌面日历：四种视图、灵活可调的重复日程、可自定义的工作休息节奏与上下班时间、跨周 / 跨月 / 跨年的长期计划、法定节假日与调休、四种桌面小组件，以及一套完整的设置中心。所有数据只保存在本机。

[English](README.en.md) · [离线 HTML 说明](README.html) · [GitHub](https://github.com/yaolongda/Morrow)

## 下载

前往 **[Releases](../../releases/latest)** 下载最新 Windows 安装包：

- 可在「设置 → 应用」中卸载，卸载不会删除日程数据

## 核心功能

### 日历

- 月 / 周 / 日 / 年四种视图，今天高亮，支持全天、多日与跨月日程。
- 周 / 日视图拖出时间段即可新建日程；月视图双击日期快速创建。
- 多日历配色、显隐、右键重命名或删除；标题 / 地点 / 备注即时搜索。
- 本地 JSON 原子持久化，不联网、不上传。

### 重复日程

- 支持 **每天、每个工作日、每周（任选星期几）、每两周、每月、每季度、每年** 七种重复方式。
- 可设置重复结束日期；留空表示一直重复。
- 编辑重复日程时，可选择 **仅此日程** 或 **所有日程**：前者只修改／删除当次，后者更新整个系列，移动日期时整个系列会一起平移。
- 重复实例在月、周、日、年视图与四种桌面小组件中自动展开，并以 ↻ 标记提示。
- 搜索结果会定位到最近一次重复实例，而不是系列第一次出现的日期。

### 上下班与下班庆祝

- 在「设置 → 工作时间」里设置班次：**上午 + 下午**、**全天** 或 **夜班**，并分别填写上下班时间。
- 「今天」小组件会显示实时状态：距上班、距午休、距下班还有多久；休息日则安静地写一句「好好生活」。
- 午休时有一场轻量的庆祝；真正下班时，会有更完整的粒子动画和一句下班诗。
- 如果第二天是周末或法定节假日，最后一天下班的庆祝会自动升级，诗也会换成「假期前夜」的那一首。
- 夜班按跨午夜处理，早上结束同样会庆祝。
- 所有庆祝只发生在「今天」小组件里，不弹系统通知，不打断你正在做的事。

![上下班时间](docs/settings-work-hours.png)

### 法定节假日

- 内置 **2024–2026** 年中国法定节假日与调休补班安排：放假自动标为休息，调休日自动标为上班。
- 月视图会显示节日名称，设置中心的特殊日期会标出节日圆点。
- 特殊日期优先级最高：把某一天点成「补班」，就是「今天加班，不放假」。
- 可以在「设置 → 工作时间」关闭节假日同步，完全按自己的休息规则走。

### 工作节奏

- 自定义每周起始日：**周一 / 周日 / 周六**。
- 休息规则预设：
  - 双休、单休
  - 大小周（大周双休、小周单休）
  - 上三休一
  - 周六上半天
  - 周六半天大小周
  - 月休五天（自设）
  - 完全自定义：逐天设置工作 / 半天 / 休息
- **特殊日期**：任选日期切换为休息、半天或补班，支持调休与临时安排。
- 休息日会在月 / 周 / 日 / 年视图、迷你日历与桌面小组件中柔和高亮，并随时同步。

![工作时间设置](docs/settings-work.png)

### 长期计划

- 给计划设置开始与结束日期，支持从几号持续到几号。
- 自动识别并视觉区分：
  - **短期 · 跨周**：3 周以内
  - **中期 · 跨月**：3 周至约 4 个月
  - **长期 · 跨年**：超过 4 个月或跨年
- 在月视图中以浅色进度条横跨日期，在周 / 日视图中显示计划带，不喧宾夺主。
- **按时间自动推进**：新建计划默认按日期自动计算进度，也可以关掉开关手动拖动。
- **自定义提醒节点**：在计划里添加「第一阶段验收」「中期复盘」这样的日期；到节点当天，会弹出一张温和的提醒卡，配一句诗，不会用系统通知打断你。
- 经过 **20 / 50 / 75 / 80 / 90 / 100%** 里程碑时，会随机送上一句励志古诗。
- 临近截止时，用一句诗温和提醒；侧边栏展示进行中的计划、进度与今日节点。

![计划编辑器](docs/plan-editor.png)

### 桌面小组件

四种小组件：月历、今天、即将到来、月历与议程。

- 拖动卡片自由移动；**不再限制大 / 中 / 小预设尺寸**，拖动右下角手柄或窗口边缘即可像主窗口一样自由缩放。
- 布局会随尺寸自动变化：宽屏时月历与议程并排，窄屏时自动堆叠；字号和可见日程数量也会跟着调整。
- 小组件跟随全局主题、强调色、字体、面板透明度、毛玻璃与背景图片，并带有轻微的入场动画。
- **锁定位置与尺寸**后固定不动；置顶、关闭；位置、尺寸与锁定状态会在重启后恢复。
- 今日小组件显示农历、节气与上下班倒计时，并在下班时播放庆祝动画。
- 点击小组件中的日期或日程，会打开主日历并定位。

### 设置中心

点击工具栏齿轮，或按 `Ctrl + ,`：

- **通用**：周起始日、侧边栏、配置导入导出、数据文件夹。
- **工作时间**：休息规则预设、自定义工作日、上下班班次与时间、法定节假日同步、特殊日期调休 / 加班。
- **外观**：
  - 经典白 / 暖纸 / 晨雾三套主题
  - 强调色（7 种预设 + 自选颜色）
  - 字体（系统、微软雅黑、等线、宋体、楷体、霞鹜文楷）
  - Windows 11 **Mica / 亚克力**窗口材质
  - 面板不透明度、毛玻璃模糊
  - 导入自己的背景图片，可调节透明度、模糊与暗化
- **显示**：农历、二十四节气、黄历宜忌、星座运势，以及计划显示开关。
- **计划**：计划类型说明、进行中的计划、新建计划。- **关于**：版本、简介、Slogan、项目主页与检查更新。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `T` | 回到今天 |

## 从源码运行

```powershell
npm install
npm start
```

如 Electron 下载缓慢，可先设置镜像：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
npm install
```

## 构建

```powershell
npm run dist
# 输出：dist\朝暮-Morrow-Setup-1.1.0.exe

npm run build:portable
# 输出：release\朝暮-win32-x64\朝暮.exe
```

## 数据与隐私

```text
%APPDATA%\朝暮\
├─ calendar-data.json    # 日历、日程、计划与设置
├─ widgets.json          # 小组件位置、尺寸、置顶与锁定
└─ window-state.json     # 主窗口大小与位置
```

- 不访问网络、不上传任何数据。
- 配置导出包含全部日历、日程、计划、设置与小组件布局。
- 删除 `calendar-data.json` 可恢复示例数据；卸载不会自动删除数据。
- 从旧版「日历」升级时，会自动迁移原有日程与小组件数据。

## 技术栈

- Electron 45
- 原生 HTML / CSS / JavaScript，无前端框架、无运行时 NPM 依赖
- 浏览器内置 Intl 中国历法 + 太阳黄经节气计算
- 法定节假日与调休数据本地内置（chinese-days，MIT）
- Chromium DevTools Protocol 端到端测试
- electron-builder + NSIS

## 已知边界

- 农历与节气为本地计算；黄历宜忌为传统建除十二神的简化呈现，星座运势为本地生成的娱乐内容。
- 法定节假日数据内置 2024–2026 年安排（来源 chinese-days，MIT）；更晚年份会回退到普通周末规则，可通过特殊日期手动补充。
- Mica / 亚克力需要 Windows 11；旧系统会回退到普通窗口。
- 团队协作、账户同步与系统通知提醒尚未实现；周数显示也暂未加入。
- 安装包与便携版未签名，SmartScreen 可能提示。
- 小组件是独立窗口，置顶时会浮于其它应用之上。
