OVERVIEW

功能一览

参考 macOS 自带日历的视觉与操作习惯：干净的白色画布、左侧迷你日历、彩色日程块，以及在桌面上常驻的小组件。

四种视图

月、周、日、年视图切换。今天以红色高亮，跨月与多日日程都能自然呈现。

快速创建

周/日视图拖出时间区间即可新建；月视图双击日期快速创建；Ctrl + N 随时新建。

重复日程

每天、工作日、每周任选星期、每两周、每月、每季度、每年；可设结束日期，编辑时选择「仅此日程 / 所有日程」。

上下班与下班庆祝

上午/下午、全天或夜班；今天小组件倒计时，下班播放粒子动画与一句诗，节前自动增强。

日程提醒

提前 5 / 15 / 30 分钟、1 小时、1 天或自定义；应用内提醒卡 + 可选 Windows 通知，托盘后台也能触发。

撤销与回收站

Ctrl+Z 撤销日程和计划操作；删除的项目进入回收站保留 30 天，可恢复。

法定节假日

内置 2024–2026 年放假与调休安排，自动休息/上班；可导入 JSON 扩展未来年份，特殊日期可设为加班。

班次与批量调休

常用班次保存成模板一键切换；特殊日期可按日期段批量标记补班 / 休息 / 半天。

多日历与配色

工作、个人、家庭分别配色，可单独显示/隐藏；右键日历可重命名或删除。

搜索与跳转

按标题、地点、备注即时搜索。点击结果直接定位日期并打开日程。

完整日程信息

全天开关、开始/结束日期时间、地点、备注；周/日视图按真实时间轴排版。

桌面小组件

月历、今天、即将到来、月历与议程。拖动摆放、置顶或关闭，位置和状态会被记住。

配置备份与迁移

⋯ 菜单一键导出/导入。备份包含日历、全部日程、计划、设置与小组件布局，导入前确认覆盖。

自定义工作节奏

周起始日、双休 / 单休 / 大小周 / 上三休一 / 周六半天 / 月休五天 / 完全自定义，以及调休与补班。

长期计划

跨周、跨月、跨年计划，进度条与里程碑；达到 20/50/75/80/90/100% 时送上一句励志古诗。

完整设置中心

三套主题、字体、强调色、Mica / 亚克力、毛玻璃、背景图片，以及农历、节气、黄历、星座开关。

WORK RHYTHM

工作节奏与休息日

不是每个人都在周末休息。朝暮把「哪天上半天、哪周双休、这个月哪几天调休」变成可配置的规则，并同步到每一种视图与小组件。

周起始日

周一、周日或周六开头，月历、年历与小组件列顺序一起改变。

预设规则

双休、单休、大小周、上三休一、周六上半天、周六半天大小周、月休五天（自设）。

自定义

逐天设置工作 / 半天 / 休息；再在特殊日期中补上调休、补班与例外。

全局同步

休息日与半天在月 / 周 / 日 / 年、迷你日历和所有桌面小组件中柔和高亮。

上下班时间

上午 + 下午、全天、夜班三种班次；今天小组件会显示距上班 / 午休 / 下班的时间。班次可存成模板一键切换。

法定节假日

2024–2026 年放假与调休自动同步；可导入 JSON 扩展未来年份。特殊日期优先级更高，可把节日设为加班。

OFF-WORK MOMENTS

下班庆祝

如果桌面上有「今天」小组件，下班这件事会被认真对待一下。

  • 午休时是一场轻量的庆祝：少量光点、一句短诗，提醒你先好好吃饭。
  • 真正下班时，粒子更多、动画更完整，并送上一句下班诗。
  • 如果第二天是周末或法定节假日，庆祝会自动升级为「假期前夜」，诗也会换掉。
  • 夜班按跨午夜处理，早上结束时同样会庆祝。
  • 所有庆祝只发生在小组件里，不弹系统通知，不抢焦点。

LONG-RUNNING PLANS

长期计划与里程碑

为研发计划、项目阶段或年度目标设置一个持续的日期范围。朝暮会自动识别短期、中期与长期，并在日历里留下不打扰的进度痕迹。

  • 短期 · 跨周：3 周以内，适合迭代、冲刺与短期研发。
  • 中期 · 跨月：3 周至约 4 个月，适合项目阶段与季度目标。
  • 长期 · 跨年：超过 4 个月或跨年，适合年度计划。
  • 月视图中的浅色进度带、周 / 日视图中的计划带，均可点击打开。
  • 按时间自动推进：新建计划默认随日期自动增长进度，也可以关掉开关手动拖动。
  • 自定义提醒节点：添加日期与名称，节点当天弹出一张温和的提醒卡与一句诗，不使用系统通知。
  • 归档与筛选：按进行中 / 已完成 / 已归档查看计划，结束的计划不用删除。
  • 进度经过 20 / 50 / 75 / 80 / 90 / 100% 时随机出现一句励志古诗；每个里程碑也可以自定义文案。
  • 侧边栏显示进行中的计划、进度与「今日节点」。

GET STARTED

下载与起步

下载安装包

前往本仓库的 Releases 页面，下载最新的 Windows 安装包：

朝暮-Morrow-Setup-1.2.0.exe

系统要求 Windows 10 / 11（x64）。默认按当前用户安装，无需管理员权限；会创建桌面与开始菜单快捷方式，可在「设置 → 应用」中卸载。安装包未做代码签名，首次运行若出现 SmartScreen，请选择「更多信息 → 仍要运行」。

从源码运行

npm install
npm start

项目已内置 Electron。若下载缓慢，可设置镜像：

$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
npm install

构建

npm run dist
# dist\朝暮-Morrow-Setup-1.2.0.exe

npm run build:portable
# release\朝暮-win32-x64\朝暮.exe

安装包约 107 MB，因此作为 GitHub Release 附件发布，不提交到源码仓库。

第一次启动会生成一组相对当天的示例日程，方便你立即体验各视图与小组件；可以自由修改或删除。

日程

  • 点击 +、按 Ctrl + N，或双击月视图空白日期新建日程。
  • 在周/日视图的空白时间列按住并向下拖动，框选时间段后新建。
  • 点击任意日程打开编辑器；在编辑器中点击「删除日程」。
  • 重复日程可选择「仅此日程 / 此后全部 / 所有日程」；删除同样提供三个范围。
  • 可为日程设置提醒：提前 5 / 15 / 30 分钟、1 小时、1 天或自定义分钟数，并可选 Windows 通知。
  • 周 / 日视图的全天日程过多时会自动折叠为「还有 N 个全天日程」，点一下展开。
  • 「全天」开关隐藏具体时间，只按日期显示。
  • 编辑器中按 Ctrl + Enter 保存，Esc 取消。

重复日程

  • 在编辑器「重复」中选择：每天、每个工作日、每周（任选星期几）、每两周、每月、每季度、每年。
  • 「结束于」可设置重复截止日期；留空表示一直重复。
  • 打开任意一次重复日程时，可选择 仅此日程 或 所有日程：前者只改当次，后者更新整个系列。
  • 删除时同样按范围处理：只删当次会记为例外日期，删除所有日程会移除整个系列。
  • 重复实例会展开到所有视图与桌面小组件，并以 ↻ 标记提示。

日历分组

  • 「我的日历」右侧 + 新建日历，可选 7 种颜色。
  • 点击日历名称可显示/隐藏该日历的所有日程。
  • 在日历上右键可以重命名或删除；删除日历会连同日程一起删除，并会先确认。

搜索

顶部搜索框输入关键字即可；Ctrl + F 或 / 聚焦搜索框。点击结果会跳转到对应日期并打开日程。

配置导出与导入

点击工具栏右侧的 ⋯：

  • 导出配置…：选择保存位置，生成一个 .json 备份，包含所有日历、日程、界面设置和桌面小组件布局（位置、置顶状态）。
  • 导入配置…：选择备份文件后，会先显示将被覆盖的日历、日程和小组件数量；确认后替换当前数据。
  • 支持导入本应用导出的配置包，也兼容直接导入数据目录里的 calendar-data.json（这种文件不包含小组件布局，导入时会保留现有小组件）。
  • 导入前建议先导出一份当前配置作为兜底。此操作无法撤销。

  • 鼠标移到小组件上，右上角出现置顶与关闭按钮。
  • 拖动卡片（标题或空白处）可移动，位置会自动保存。

  • 大号小组件单击日期切换下方议程；点击日期或日程会打开主日历对应位置。

DATA & PRIVACY

数据与隐私

所有数据只保存在本机，应用不访问网络、不上传任何内容。

%APPDATA%\朝暮\ ├─ calendar-data.json # 日历、日程、计划与设置 ├─ widgets.json # 小组件位置、尺寸、置顶与锁定 └─ window-state.json # 主窗口大小与位置

备份时复制 calendar-data.json 即可；也可以使用 ⋯ → 导出配置… 一键备份全部内容（含计划、设置与小组件布局）。删除该文件可恢复示例数据；卸载应用不会自动删除上述数据，如需彻底清除请手动删除 %APPDATA%\朝暮。从旧版「日历」升级时，会自动迁移原有日程与小组件数据。
